# 涛博士运动康复 · 静态交互设计原型

用于查看与讨论界面和工作流程。所有姓名、门店、预约、计划、收款和业绩均为虚构示例。

支持客户、康复师、老板和前台角色体验；可模拟到店、服务照片留底、消课、收款、退款记录、平台待结算与到账。本页面不会执行真实付款或退款。

页面数据仅保存在当前访客页面内存中，刷新恢复初始示例。未接入微信登录、真实客户档案、持久数据库或平台自动对账。

老板快捷入口：`?preview=boss`；前台快捷入口：`?preview=frontdesk`。这些仅选择演示角色，正式系统必须使用真实身份和服务端权限。

客户分享入口：`?preview=customer`。直接展示客户页面，隐藏角色切换与管理演示控件，保留计划、次数、预约、服务记录及评价体验，并持续标注示例资料。原链接及老板、前台入口继续可用。此入口是展示模式，不代表正式账号权限。
